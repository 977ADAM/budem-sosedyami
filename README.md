# Будем соседями? — SvelteKit

Демо-игра о знакомстве с будущими соседями и выборе жилого комплекса.

## Стек

- Svelte 5
- SvelteKit 2
- Vite 6
- adapter-static

## Запуск

```sh
npm install
npm run dev
```

Сборка статической страницы для публикации:

```sh
npm run build
```

Готовый сайт собирается в `dist/`.
