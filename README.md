# Будем соседями? — API для фронтенда

Чат с четырьмя вымышленными соседями. Соседи отвечают через DeepSeek и рассказывают
только то, что есть в их профиле.

## Подключение за 5 минут

Один эндпоинт:

```text
POST {API_URL}/api/agents/{agent_id}/chat
Content-Type: application/json
```

`agent_id`: `anton`, `marina`, `pavel` или `vera`.

| Поле запроса | Обязательно | Что это |
| --- | --- | --- |
| `message` | да | Текст пользователя, 1–500 символов |
| `context` | нет | `context` из предыдущего ответа этого же соседа |

Ответ `200`:

```json
{ "reply": "Во дворе есть место, где дети играют…", "context": "gAAAAABn3k…" }
```

Правило одно: **сохраните `context` из ответа и пришлите его со следующим
сообщением этому же соседу.** Нет `context` — новый разговор. Внутрь `context`
заглядывать не нужно и невозможно: это зашифрованная история диалога.

### Пример

```js
const API_URL = "https://api.example.com";
const contexts = {}; // agentId -> context

async function sendToNeighbor(agentId, message) {
  const response = await fetch(`${API_URL}/api/agents/${agentId}/chat`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ message, context: contexts[agentId] }),
  });
  const data = await response.json();
  if (!response.ok) throw new Error(data.detail); // текст можно показать пользователю
  contexts[agentId] = data.context;
  return data.reply;
}

await sendToNeighbor("marina", "Где вы гуляете после школы?");
await sendToNeighbor("marina", "А в выходные?"); // Марина помнит прошлый вопрос
```

Начать разговор заново: `delete contexts[agentId]`. Чтобы разговор пережил
перезагрузку страницы, сохраните `context` в `localStorage`.

### Ошибки

Любая ошибка приходит как `{"detail": "текст на русском"}`. Текст можно показать
пользователю без изменений. Если запрос не удался, прежний `context` остаётся
рабочим — просто повторите запрос с ним.

| Код | Когда | Что делать |
| --- | --- | --- |
| 422 | Пустое или длинное сообщение, неизвестный сосед | Исправить запрос |
| 429 | Слишком много сообщений с одного IP | Подождать минуту |
| 502 | Модель вернула ошибку | Повторить |
| 503 | На сервере не настроена модель | Сообщить владельцу API |
| 504 | Модель не ответила за 30 секунд | Повторить |

### Что важно знать

- `context` действует 24 часа. Устаревший, повреждённый или чужой `context`
  не вызывает ошибку: разговор просто начинается заново.
- У каждого соседа свой `context`. `context` Марины в чате Антона начнёт новый разговор.
- Сосед помнит последние 15–30 пар реплик.
- Ответ модели занимает несколько секунд: покажите индикатор «печатает…».
- Адрес вашего сайта должен быть в `CORS_ORIGINS` на сервере — напишите владельцу API.
- Не передавайте в чат личные данные: сообщения уходят в DeepSeek.

Интерактивная документация и OpenAPI-схема: `{API_URL}/docs` и
`{API_URL}/openapi.json`. Из схемы можно сгенерировать типизированный клиент,
например через `openapi-typescript`.
