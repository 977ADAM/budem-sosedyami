# Backend

FastAPI API для диалогов с вымышленными соседями через DeepSeek и LangGraph.
Сервер не сохраняет историю и не использует сессии, cookie или PostgreSQL.

## Запуск

```sh
cd backend
uv sync
cp .env.example .env
# Задайте DEEPSEEK_API_KEY в .env
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Разрешённые адреса frontend задаются в `CORS_ORIGINS`.
Проверка состояния: `GET http://127.0.0.1:8000/health`.
Миграции и DATABASE_URL больше не нужны.

## Чат API

`POST /api/agents/{agent_id}/chat`, где ID — `anton`, `marina`, `pavel` или `vera`.

```json
{
  "message": "А где ещё можно погулять?",
  "history": [
    {"message": "Где ты обычно бегаешь?", "reply": "В парке рядом с домом."}
  ]
}
```

Ответ: `{"reply": "Ответ соседа"}`. История необязательна; без неё начинается
новый диалог. Сервер сам добавляет системный профиль выбранного соседа.
Новое сообщение и сообщения пользователя в истории ограничены 500 символами,
ответ в истории — 20000 символами, история — 100 завершёнными парами реплик.
Браузер отправляет последние 100 успешных пар только выбранного соседа;
ошибочные и ожидающие ответа сообщения в контекст не попадают.

История хранится только в памяти вкладки, отдельно для каждого соседа.
Обновление или закрытие страницы очищает её. Кнопка «Очистить диалоги»
очищает все диалоги вкладки без запроса к серверу.
Контекст передаётся через backend в DeepSeek для генерации ответа.
Не передавайте в чат личные данные.

Старые маршруты `/api/session` и `/api/agents/{agent_id}/history` удалены.
Ранее записанные данные в PostgreSQL автоматически не удаляются; новое
приложение к этой базе не подключается.
