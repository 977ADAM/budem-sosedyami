# Backend

Локальный FastAPI API для демо-соседей. Вызовы DeepSeek выполняются через
LangChain `ChatOpenAI` и OpenAI-совместимый API. Python-зависимости и виртуальное
окружение управляются через `uv`; `requirements.txt` не используется.

## Подготовка

```sh
cd backend
uv sync
cp .env.example .env
```

Добавьте `DEEPSEEK_API_KEY` в `.env`. Без ключа сервер запустится, но запросы
к модели будут отвечать ошибкой `503`.

## Запуск

```sh
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

API будет доступен только на локальном компьютере по адресу
`http://127.0.0.1:8000`. Проверка состояния: `http://127.0.0.1:8000/health`.
`uv run` использует версии библиотек из `uv.lock`; после изменения зависимостей
обновите lock-файл командой `uv lock` и окружение командой `uv sync`.

## Чат API

Для чата используется один endpoint; ID агента задаётся в пути:

- `POST /api/agents/{agent_id}/chat` (`anton`, `marina`, `pavel` или `vera`)

Пример тела запроса:

```json
{
  "message": "Где ты обычно бегаешь?",
  "history": [
    {
      "message": "Где ты работаешь?",
      "reply": "Я дизайнер и работаю из дома у окна."
    }
  ]
}
```

`message` и каждый `history[].message` должны быть длиной от 1 до 500 символов;
в `history` можно передать до 10 предыдущих реплик. На первом ходу передавайте
пустой массив `history`. Историю держит frontend в памяти страницы и отправляет
с каждым запросом; backend не сохраняет реплики и возвращает только
`{"reply": "..."}`. Агент отвечает только по вымышленному профилю; не
передавайте в чат личные данные.
